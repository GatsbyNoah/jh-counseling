❓ 使用說明

    
三步驟完成一筆紀錄

    
    
      
  1. 填寫情境：選學生、類別與標籤，用口語寫下（或用說的）發生什麼事。
    2. 
      
  2. AI 產生：按「✨ AI 整理成輔導紀錄」，自動寫成「輔導內容重點」與「聯繫內容」兩段。
    3. 
      
  3. 檢查後複製：核對事實、微調用詞，再複製貼到校務系統（如輔導紀錄或學生輔導資料 B 表）。
    4. 
    

    
和國小版不一樣的地方

    
    
      
  • 年級為七～九年級；類別與標籤改為國中常見議題：會考壓力、生涯／適性入學、網路與 3C、情感交往、電子煙、拒學等。
    • 
      
  • 可註明三級輔導層級與紀錄者身分（導師、專輔教師、生教組…），AI 會依身分調整用語。
    • 
      
  • 通報提醒：選到霸凌、性平、家暴／疏忽、自傷、藥物、中輟等標籤時，會跳出提醒。這只是提醒，實際仍請依學校流程並與輔導室、學務處確認。
    • 
      
  • AI 撰寫時會用尊重青少年自主的語言，並記下學生自己的想法與承諾。
    • 
    

    
隱私保護

    
    
      
  • 學生姓名、相關人物、名冊姓名在送出前都會換成「甲生、乙生…」，電話與身分證字號會被遮蔽；AI 寫完後才在你的瀏覽器換回真名。
    • 
      
  • 紀錄本、名冊、草稿只存在這台電腦的瀏覽器；換電腦或清除瀏覽資料就會不見，請定期「備份成檔案」。
    • 
      
  • 公用電腦請在設定中開啟「公用電腦模式」。
    • 
    

    
AI 來源

    
    
      
  • 在 Claude 裡開啟本頁時，直接使用 Claude 撰寫，不需要金鑰（第一次會詢問是否同意）。
    • 
      
  • 把本頁 HTML 放到自己的網站（例如 GitHub Pages）時，可在設定填入 Gemini API 金鑰。
    • 
      
  • 都沒有的話：按「📋 複製提示詞」貼到 Gemini 或 ChatGPT 網頁版，再把回覆貼回來自動拆段。
