# 🏫 國中輔導紀錄小幫手

把老師口語描述的輔導情形，整理成正式的「輔導內容重點」與「聯繫內容」，方便複製到校務系統。七～九年級版。

改編自阿凱老師的國小版[輔導紀錄小幫手](https://cagoooo.github.io/counseling/)。

## 功能

- **個別輔導**：選學生、類別與狀況標籤，用口語寫下經過，AI 整理成兩段紀錄；可一鍵改寫（更溫和、更客觀、更精簡、更完整）。
- **批次補登（座號制）**：一次最多 10 位，勾選優良表現、待改進表現、教師處置，並可填「必要提及」（日期會照原樣保留）。
- **國中議題**：會考壓力、生涯與適性入學、網路與 3C、情感與性別、電子煙、拒學等；可註明三級輔導層級與紀錄者身分。
- **通報提醒**：選到霸凌、性平、家暴、自傷、藥物、中輟等標籤時跳出提醒（僅供提醒，請依學校最新流程）。
- **紀錄本**：學期統計、備份成檔案、匯出 CSV。

## 怎麼使用 AI

打開網頁後有兩種方式：

1. **自己的 Gemini 金鑰**（推薦）：到 [Google AI Studio](https://aistudio.google.com/apikey) 用個人 Google 帳號免費申請金鑰（學校帳號可能無法申請），在「⚙️ 設定」貼上並按「測試並儲存」。
2. **不用金鑰**：按「📋 複製提示詞」，貼到 Gemini 或 ChatGPT 網頁版，再把回覆貼回工具，會自動拆成兩段。

## 隱私

- 學生姓名、相關人物與名冊姓名在送給 AI 前會換成「甲生、乙生…」或座號，電話與身分證字號會被遮蔽；產生後才在本機換回真名。
- 紀錄本、名冊、草稿只存在使用者自己的瀏覽器，不會上傳到任何伺服器。換電腦或清除瀏覽資料就會消失，請定期「備份成檔案」。
- 公用電腦請在設定開啟「公用電腦模式」，也不要勾選「記住金鑰」。
- Gemini 免費方案的輸入內容可能被 Google 用於改善服務，請維持去識別化。

## 部署

整個工具就是一個 `index.html`，沒有後端。開啟 GitHub Pages（Settings → Pages → Deploy from a branch → `main` / root）即可使用。
